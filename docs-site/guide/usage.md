# 日常使用

NaviDash 的主画布是日常首页，底部工具条负责添加内容、搜索和调整布局。

## 添加组件

1. 点击底部工具条的“组件库”。
2. 搜索或浏览需要的 Widget。
3. 点击添加，或将组件拖到画布上的目标位置。

部分组件首次添加后会自动打开设置面板。组件库当前包含 Links、Today、Memo、Poster、F1
和 Komari，具体用途见 [Widget 说明](/guide/widgets)。

## 编辑画布

- 点击底部工具条的“自定义”进入编辑模式。
- 拖动组件左上角手柄调整位置。
- 点击组件右上角设置按钮修改尺寸或内容。
- 点击“完成”退出编辑模式。

桌面与手机使用独立布局。调整一端的布局不会覆盖另一端；发生碰撞时，应用会进行受控的
重排并保留其他组件。

## 快速启动器

在非编辑状态、且焦点不在输入框时，可以直接输入字符，或使用 `Ctrl/⌘ + K` 打开启动器。

- 使用方向键选择结果，按 `Enter` 打开，按 `Escape` 关闭。
- 没有匹配链接时，按 `Enter` 使用启动器选择的搜索引擎搜索网页。
- 启动器会根据 NaviDash 发起的打开行为，在当前浏览器中逐步优化结果顺序。
- 学习记录默认保存在当前浏览器，不会移动画布组件，也不会默认上传到服务器。

书签库是启动器的完整来源；Links Widget 只引用固定到首页的少量书签。从 Widget 中移除书签
不会删除书签库中的原始链接。

## 全局设置

通过底部工具条的“设置”打开全局设置：

- **外观**：背景预设、自定义背景图、模糊和遮罩透明度。
- **语言**：切换界面语言。
- **数据工具**：应用模板、导入浏览器书签、导出/导入 JSON 和恢复默认。

应用模板和导入备份会替换当前组件与布局，操作前建议先导出 JSON 备份。

## Demo 模式

Demo 模式适合预览和测试：页面可以交互，但刷新后会恢复预置内容，写入不会真正持久化。
个人长期使用时请保持 `DEMO_MODE=false` 和 `NEXT_PUBLIC_DEMO_MODE=false`。

更多交互说明见[仓库内完整用户指南](https://github.com/wtfllix/navidash/blob/master/docs/USER_GUIDE.md)。
