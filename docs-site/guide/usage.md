# 日常使用

部署完成后，先从书签和少量常用 Widget 开始。桌面与手机布局相互独立，可以分别调整。

## 首次打开

服务端确认这是空白实例时，会显示首次使用引导：

1. 导入或粘贴常用书签。
2. 了解键盘快速启动器。
3. 将第一个 Widget 添加到画布。

完成引导后，其他浏览器或设备不会重复显示。如果暂时不需要导入书签，也可以直接进入空白首页。

## 导入和管理书签

打开底部 Dock 的“书签”入口，可以管理完整书签库。

### 从浏览器导入

1. 在浏览器中将书签导出为 HTML 文件。
2. 打开 NaviDash“设置 → 数据工具”。
3. 选择浏览器书签导入，并上传 HTML 文件。
4. 检查识别数量后确认导入。

导入只增加书签，不会自动把所有链接铺到首页。

### 批量粘贴链接

书签入口和 Links Widget 设置都支持批量粘贴 Markdown 链接或纯 HTTP(S) URL。从 Links 设置中
粘贴时，链接会写入书签库并同时固定到当前 Widget。

## 添加 Widget

1. 点击底部工具条的“组件库”。
2. 搜索或横向浏览 Widget。
3. 点击添加，或将 Widget 拖到画布上的目标位置。
4. 某些 Widget 首次添加后会自动打开设置面板。

组件库包含 Links、Today、Memo、Poster、F1 和 Komari。具体设置见 [Widget 说明](./widgets)。

## 移动、调整和删除

1. 点击底部工具条的“自定义”进入编辑模式。
2. 拖动 Widget 左上角手柄调整位置。
3. 点击右上角设置按钮修改尺寸或配置。
4. 使用删除按钮移除 Widget。
5. 点击“完成”退出编辑模式。

目标位置被占用时，系统会进行受控重排。调整尺寸发生冲突时会拒绝操作，避免意外推动整个布局。
删除 Links Widget 不会删除书签库中的链接。

## 桌面与手机布局

- 桌面使用 8 个逻辑列。
- 手机使用 2 个逻辑列。
- 两端共享 Widget 内容，但分别保存位置和尺寸。
- 在桌面移动 Widget 不会重排手机布局，反之亦然。

建议分别用桌面浏览器和手机检查一次布局，再进行备份。

## 快速启动器

在非编辑状态、且焦点不在输入框时，直接输入字符，或按 `Ctrl/⌘ + K` 打开启动器。

- 使用方向键选择结果，按 `Enter` 打开，按 `Escape` 关闭。
- 没有匹配链接时，按 `Enter` 使用选中的搜索引擎搜索网页。
- 启动器会根据 NaviDash 发起的打开行为，在当前浏览器中逐步优化结果顺序。
- 学习记录默认只保存在当前浏览器，可在“设置 → 数据工具”中查看或清除。

启动器搜索整个书签库，Links Widget 只展示其中被固定到首页的链接。

## 外观与页面设置

打开“设置 → 外观”可以调整：

- 背景预设或自定义背景图
- 背景模糊度
- 遮罩透明度
- 高级选项中的页面标题和 Favicon

设置会自动保存，不需要额外点击保存按钮。

## 导出当前配置

完成布局后，打开“设置 → 数据工具”导出 JSON。它包含书签、Widget 配置、桌面与手机布局以及
全局设置。完整的宿主机备份方法见[升级与备份](./backup)。
