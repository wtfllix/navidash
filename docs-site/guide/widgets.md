# Widget 说明

NaviDash 当前提供六种核心组件。组件的身份和配置在首页中共享，桌面与手机分别保存布局。

## Links · 常用入口

把书签库中的常用网站固定到首页。

- `1×1` 适合一个高频入口。
- 横向尺寸适合一组网站或服务。
- 显示顺序由用户维护，不会因为启动器学习记录自动交换。

## Today · 今日信息

将时间、日期和天气组合在一张信息牌中。天气不可用时，时间与日期仍会继续显示。

天气服务通过服务端代理访问，API Key、Host 和认证方式配置在部署主机的环境变量中；组件本身
只保存城市或坐标。

## Memo · 随手贴

适合临时保存文字、链接和轻量 Markdown。内容直接在组件内编辑并自动保存，不承担完整笔记或
任务管理功能。

## Poster · 海报

使用一张或多张图片装饰首页。默认无外框、静止显示；需要时可以开启轮播并设置间隔。

## F1 · 赛程与积分

F1 是只读的赛事摘要，可在组件设置中切换两种模式：

- **赛程**：使用应用内置的 2026 赛季数据，按设备本地时区显示下一场排位、冲刺或正赛。
- **车手积分**：由服务端从 Jolpica 获取当前赛季排名，成功结果缓存 24 小时。

积分模式不是秒级实时比分。上游暂时不可用时，组件会优先显示最近一次成功缓存；首次请求且
没有缓存时会保留布局并显示降级状态。

## Komari · 节点状态

每张 Komari 组件绑定一台节点，展示在线状态、运行时间、CPU、内存、硬盘、网络和流量等信息。

- 默认尺寸为 `2×2`，也支持 `2×1` 和 `1×1` 紧凑版本。
- Komari 地址和可选 API Key 只配置在服务端环境变量中。
- 每张组件只绑定一台节点，需要关注多台服务器时添加多张组件。
- NaviDash 只读节点状态，不提供终端、任务执行或 Komari 管理功能。

## 尺寸选择建议

| 尺寸 | 适合场景 |
| --- | --- |
| `1×1` | 单个入口、极简信息或 Komari 概览 |
| `2×1` | 横向 Links、F1 小卡或 Komari 紧凑卡 |
| `2×2` | Today、Poster、完整 F1 或 Komari 卡 |
| `3×2` | F1 车手积分榜，显示完整排名 |
