# Widget 说明与配置

进入编辑模式后，点击 Widget 右上角的设置按钮即可调整尺寸和配置。Memo 直接在卡片内编辑。

## Links · 常用入口

### 添加和配置

1. 从组件库添加 Links。
2. 打开设置，从书签库勾选要固定的链接。
3. 拖动列表调整显示顺序。
4. 按需设置标题、标签显示和图标尺寸。

`1×1` 适合单个高频入口，横向尺寸适合一组常用网站。Links 只引用书签库内容：从 Widget 中
移除链接或删除整个 Widget，都不会删除原始书签。

## Today · 时间、日期和天气

### 使用前配置

如果需要天气，先按[服务配置](./configuration#today-天气)填写和风天气环境变量并测试连接。

### Widget 设置

1. 从组件库添加 Today。
2. 打开设置，输入城市名称。
3. 从匹配结果中选择城市或经纬度。

天气服务不可用时，Widget 仍会继续显示本地时间和日期。Today 使用固定 `2×2` 信息牌布局。

## Memo · 随手贴

Memo 添加后即可直接输入内容，并自动保存。支持标题、列表、链接和引用等轻量 Markdown 样式。

- 适合临时文字、待复制内容和短链接。
- 不需要进入设置面板编辑正文。
- 不建议用作完整笔记库或任务管理工具。

## Poster · 海报

1. 从组件库添加 Poster。
2. 在设置中添加一张或多张图片地址。
3. 需要轮播时开启自动播放，并设置切换间隔。
4. 不需要轮播时保持默认关闭。

Poster 默认无边框显示。外部图片无法加载时，先确认图片地址可以公开访问，且没有指向本机或
局域网保留地址。

## F1 · 赛程与车手积分

F1 不需要账户或日历地址。打开设置后选择显示模式：

- **赛程**：显示下一赛段和同一比赛周末的后续赛段。
- **车手积分**：显示 Jolpica 最近发布的当前赛季排名。

赛程模式还可以设置：

- 是否显示练习赛
- 是否显示倒计时

所有赛段时间都会转换为当前设备时区。积分成功结果缓存 24 小时，不是比赛过程中的秒级实时
数据。`3×2` 适合完整积分榜，`2×2` 显示前四名，`2×1` 显示前三名。

## Komari · 节点状态

### 使用前配置

先按[服务配置](./configuration#komari-节点)填写 `KOMARI_BASE_URL` 和可选 API Key，重启容器。

### Widget 设置

1. 从组件库添加 Komari。
2. 打开设置并选择一台节点。
3. 选择是否显示实时上下行速率。
4. 将刷新间隔设置为 5、15 或 30 秒。

每张 Widget 只绑定一台节点。需要关注多台服务器时，添加多张 Komari Widget。

| 尺寸    | 显示内容                  |
| ----- | --------------------- |
| `1×1` | 节点身份、运行时间、CPU、内存和硬盘概览 |
| `2×1` | 增加紧凑资源信息与可选实时速率       |
| `2×2` | 完整资源、网络、流量和更新时间       |

NaviDash 只读节点状态，不提供远程终端、任务执行或 Komari 管理功能。

## 尺寸调整失败

如果新尺寸会与其他 Widget 发生冲突，系统会拒绝调整。先移动周围 Widget 留出空间，再重新打开
设置选择尺寸。桌面和手机布局需要分别调整。
