# NaviDash 产品设想

## 产品愿景

NaviDash 是为自托管与效率爱好者设计的注意力优先型私人浏览器主页。用户可以通过自由
布局，把常用入口、日常信息与个人内容组织成真正属于自己的首页。

它也可以被理解为一面私人数字墙：常用入口是墙上的工具，今日信息是一块安静的信息牌，
Memo 是随手贴，Poster 是用于建立空间氛围的海报。墙面允许个性化，但不能因为装饰而
降低用户找到下一步的速度。

对外表达：

> 把每天打开的首页，布置成自己的样子。

## 核心问题

浏览器默认首页通常只有搜索和少量自动推荐；传统 Dashboard 又容易堆叠过多信息，让用户
在真正开始工作前先处理界面。NaviDash 希望让用户打开页面后快速识别下一步，同时保留
少量有用信息和个人氛围。

主页不是目的地，而是进入下一件事的中转页。产品成功不以停留时长衡量，而以找到并打开
目标所需的时间和按键数衡量。

## 目标用户

- 重视效率、个性化和数据控制权的个人用户。
- 愿意自托管，但不一定是重度 Homelab 用户。
- 希望首页比浏览器默认页丰富，又不想使用重型 Dashboard。

## 产品原则

1. **注意力优先**：高频 Action 内容始终拥有最高视觉和交互优先级。
2. **空间记忆稳定**：用户摆放的内容不应被系统擅自移动。
3. **使用越久越顺手**：启动器通过本地使用习惯学习个人快捷路径。
4. **克制的信息层级**：Glance 内容安静可扫读，Ambient 内容不争夺焦点。
5. **数据属于用户**：本地优先、自托管、可备份、可迁移、可清除。

## 能力地图

### Action

- 直接输入唤起的自学习启动器。
- 完整书签库、网页搜索和稳定摆放的固定 Links。
- 键盘优先的快速打开路径。

### Glance

- 合并时间、日期和天气的 Today 信息面板。
- 以内置赛季数据显示下一赛段和比赛周末安排的 F1 赛程摘要。
- 信息应在几秒内看懂，无需持续交互。

### Ambient

- 背景与无外框的 Poster。
- 提供熟悉感和情绪价值，但不得压过 Action。

### Personal

- 用于临时粘贴文本、链接和命令的 Memo。
- 保持随手记录能力，不扩展成完整笔记或任务管理工具。

### Ownership

- Docker 自托管。
- 版本化持久化、JSON 备份和恢复。
- 默认不上传个人使用习惯。

## 非目标

- 公开展示型个人网站。
- 团队门户和协作工作台。
- 完整监控告警或 Docker 运维控制台。
- 以 Widget 数量作为主要竞争方式。
- 默认采集用户行为或完整浏览器历史。

## 成功标准

- 新用户能快速得到一个属于自己的可用首页。
- 用户愿意将 NaviDash 设置为浏览器主页或新标签页。
- 常用链接能通过很少的按键稳定打开。
- 页面布局在保存、重载和设备切换后保持可预测。
- 自托管、备份和升级过程可靠、可理解。
