# NaviDash Roadmap

路线图记录开发顺序，不承诺具体日期。功能进入实现前必须与根目录 `SPEC.md` 一致。

## 当前状态

- 当前网站版本为 `0.8.0`，已完成首次部署引导、Poster 缩略图、快照冲突恢复与 F1 赛程组件。
- `0.7.3` 已冻结为持久化兼容基线；后续 Schema 变化必须以脱敏夹具验证向前迁移。
- 下方按实际网站小版本记录已经完成的能力，不再使用提前占位的大版本标签。
- 简要阶段记录见 [`STAGE_SUMMARY_0.7.3.md`](./STAGE_SUMMARY_0.7.3.md)。

## 当前阶段：发布后稳定与安全基础（待开始）

- 优先验证全新部署、历史数据升级、多标签冲突恢复、Poster 缓存与 F1 时区显示的真实环境反馈。
- 升级 Next.js 并加固访问会话、登录限速与安全响应头，为可选的跨设备同步或 Vault 打好基础。
- 将快速启动器改为真实输入框，在不引入敏感数据的前提下先完善空格、中文输入法和命令模式。

## 已完成能力轨迹

### v0.7.0：本地自学习启动器

- 按链接总使用频率和输入关联学习结果排序。
- 近期行为逐渐覆盖旧习惯。
- Links 与启动器统一统计。
- 学习数据默认保存在当前浏览器，支持查看、清除和备份。
- 建立 Product、Spec 和 Decision 文档体系。

### v0.7.1：注意力优先的界面收敛

- 悬浮搜索入口、`Ctrl/⌘ + K` 和画布直接输入统一进入启动器，并移除常驻 Header。
- 管理操作收敛为 macOS Dock 风格的底部工具条。
- 组件添加统一使用底部单行组件架，移除重复选择器。
- 精简全局设置，移除表现不一致的主题色与重复保存操作。
- 备份恢复完整保留桌面、手机布局与共享 Widget 配置。
- 恢复默认只操作 NaviDash 自身数据。

### v0.7.2：私人数字墙核心组件

- 将时间、日期和天气合并为 Today 信息面板。
- 常用入口支持单链接与多链接的稳定空间布局。
- Memo 提供紧凑随手贴形态。
- Poster 使用无外框图片表面并默认关闭轮播。
- 组件架与运行时类型聚焦 Links、Today、Memo 与 Poster；旧组件数据在读取时过滤。

### v0.7.3：基础重构收口

- 固定桌面 8 列与手机 2 列坐标系，完成受控碰撞、回弹与旧布局迁移。
- 将布局、配置和书签统一为带 revision 的原子快照，后台同步改为页面事件驱动。
- 增加默认关闭的单用户访问保护，以及空白、专注和数字墙首页模板。
- 建立全局书签库，支持 HTML 与 Markdown 批量导入，并由 Links 固定少量入口。

### v0.8.0：首次部署与核心组件扩展

- 新增双语三步首次部署引导，并将全新实例默认语言调整为中文。
- Poster 使用受限制的服务端代理生成渐进式 WebP 缩略图，原始图片地址保持不变。
- Widget 快照 revision 冲突改为用户明确选择保留本地或服务器版本。
- 新增内置双语 F1 赛程摘要，使用仓库内版本化数据并按设备本地时区显示。
- 自动化基线提升到 26 个测试套件、127 项测试。

## 后续方向

- 可选的跨设备学习同步；该能力依赖单用户访问保护。
- 根据真实反馈评估 Dev Pack 与克制的 RSS 摘要。
