# NaviDash 0.7.3 阶段收口

状态：已完成  
收口日期：2026-07-26  
对照基线：首次 clone 时的 `0.6.0`（Git `d19138c`）

## 阶段结果

NaviDash 从偏传统的自托管 Dashboard，收敛为注意力优先的私人浏览器主页。当前版本已经
具备稳定画布、核心组件、快速启动、书签管理、数据迁移和私人实例保护，可以作为下一阶段
组件开发的可靠基础。

## 主要变化

- **产品与界面**：建立 Product、Spec、Roadmap 和 Decision 文档；移除常驻 Header，
  将搜索、书签、组件和设置收敛到底部 Dock 与悬浮面板。
- **快速启动与书签**：增加本地自学习排序和全局书签库；Links Widget 改为引用书签，
  支持 HTML 导入、Markdown 批量粘贴和模板初始化。
- **核心组件**：组件库收敛为 Links、Today、Memo 和 Poster；Today 合并时间、日期与天气，
  Poster 保持无外框，旧 Clock、Weather、Date、Quick Link、Todo 和 Calendar 完整下线。
- **自由画布**：固定桌面 8 列、手机 2 列坐标系；加入同尺寸交换、有限同列下推、无效回弹
  和一致的碰撞预览，避免静默重排。
- **数据与同步**：布局、配置和书签统一为带 revision 的原子快照；移除短间隔轮询，改为
  首次加载、页面恢复和网络恢复时同步，并保留旧数据迁移。
- **设置与安全**：精简过时设置，天气凭据只保留在服务端；增加默认关闭的单用户访问保护，
  完善双端布局备份、恢复与安全重置。

## 兼容性说明

- `0.7.3` 是后续版本承诺连续迁移的首个持久化兼容基线。
- Snapshot v2、Settings v1 与 Backup v3 已保存脱敏夹具，后续 Schema 变化必须通过该基线
  的升级测试。
- `0.7.3` 以前的数据继续尽力读取，但不承诺完整保留已下线组件和旧画布。
- 旧布局、旧备份和旧分离 JSON 文件仍可作为迁移来源读取。
- 已下线 Widget 会被确定性过滤，其他有效组件不受影响。
- 新快照、书签引用和备份结构不再向旧版运行代码提供反向兼容。
