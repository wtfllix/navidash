# NaviDash 用户指南

欢迎使用 NaviDash。本文档基于当前版本的实际产品形态整理，帮助你快速了解页面结构、常见操作和数据管理方式。

## 界面结构

NaviDash 当前主要由三部分组成：

1. 主画布
   用于摆放和展示 widget，也是你日常使用的首页区域。
2. 底部悬浮工具条
   提供快速启动器、组件库、编辑模式和全局设置入口。
3. 底部组件架
   从悬浮工具条上方展开，用于搜索、横向浏览和添加可用 widget。

## 基本使用

### 快速启动器

- 在非编辑状态、焦点不在输入框时直接输入字符，或使用 `Ctrl/⌘ + K` 和底部搜索按钮打开
- 使用上下方向键切换结果，按 `Enter` 打开，按 `Escape` 关闭
- 没有匹配链接时，按 `Enter` 使用启动器中选择的搜索引擎搜索网页
- 启动器会在当前浏览器中学习“输入内容 → 最终打开链接”的关系
- 同时匹配多个链接时，经常为当前输入选择的目标会逐渐排在前面
- 学习数据不会移动画布组件，也不会默认上传到服务器
- 可以在“设置与数据 → 数据工具”中查看或清除学习记录

### 进入编辑模式

- 点击底部工具条中的“自定义 / 完成”按钮切换编辑模式
- 编辑模式下可以移动 widget、打开 widget 设置、删除 widget

### 打开组件库

- 点击底部工具条中的“组件库”按钮
- 组件架中可以横向浏览和搜索 widget，点击添加后会自动收起
- 也可以从组件架直接向上拖入画布，开始拖拽时组件架会自动让出空间
- 某些 widget 添加后会自动打开设置面板，方便首次配置

## Widget 操作

### 添加 widget

1. 打开组件库
2. 找到想添加的 widget
3. 点击添加，或在支持的交互中拖拽到主画布

组件库当前可以新增：

- `Links`：常用入口
- `Today`：时间、日期和天气信息牌
- `Memo`：随手粘贴信息
- `Poster`：无边框海报装饰
- `F1`：下一赛段与比赛周末摘要

旧版 `Clock`、`Weather`、`Date`、`Quick Link`、`Todo` 和 `Calendar` 已下线。读取旧布局或备份时，系统会过滤这些组件并继续保留其中的 Today、Links、Memo、Poster 和 F1。

### 移动 widget

1. 进入编辑模式
2. 按住 widget 左上角的拖拽手柄
3. 拖到目标位置后松开

当目标位置已有其他 widget 时，系统会自动进行重排和避让。

### 调整 widget 内容

不同 widget 的编辑方式不同：

- `Memo` 可以直接在组件内编辑内容，并自动保存
- `Today`、`Links`、`Poster` 和 `F1` 通过设置面板修改配置

### 打开 widget 设置

1. 进入编辑模式
2. 点击 widget 右上角的设置按钮
3. 在弹出的设置面板中修改尺寸或配置

## 常用 widget 说明

### Today

- 将时间、英文日期和实时天气组合成一块 `2×2` 信息牌
- 通过服务端 `/api/weather` 代理获取天气信息
- 在全局设置的“天气服务”中查看配置状态和测试连接
- 在 Today 设置中填写城市，或选择匹配到的经纬度
- API Key、Host 和认证方式只通过服务端环境变量配置，不写入组件数据

如果天气没有显示，请优先检查：

- `.env` 中是否已正确填写 `QWEATHER_API_KEY`
- 容器或开发服务是否已重启
- 全局设置中的连接测试是否成功
- Today 中的城市或经纬度是否正确

### Memo

- 支持直接输入内容
- 支持轻量 Markdown 样式内容，例如标题、列表、链接、引用
- 组件会自动保存内容

### Links

- `1×1` 适合一个高频入口
- 横向尺寸适合一组常用站点或服务入口
- 启动器会统计实际打开行为并逐步优化搜索排序

### Poster

- 可配置一张或多张图片
- 默认无外框且保持静止，也可主动开启轮播和设置间隔

### F1

- 使用仓库内置的 2026 赛季赛程，不需要填写 ICS 或连接外部账户
- 默认隐藏练习赛，突出下一场排位、冲刺或正赛
- 所有时间自动转换为当前设备时区
- 可在组件设置中显示练习赛或关闭倒计时
- 标记为“待确认”的比赛不会显示为正式确认赛程

## 全局设置

点击底部工具条中的“设置”按钮可以打开全局设置面板。

当前主要分为三类：

- 外观
- 语言
- 数据工具

### 外观

可调整内容包括：

- 背景预设
- 自定义背景图
- 模糊度
- 遮罩透明度
- 高级选项中的页面标题与 Favicon

### 语言

- 可切换当前界面语言

### 数据工具

支持以下能力：

- 应用空白、专注首页或个人墙模板
- 从浏览器导出的 HTML 文件导入书签
- 导出当前配置为 JSON
- 从 JSON 导入配置
- 将设置与组件恢复为默认状态

应用模板和导入备份会覆盖当前组件与布局，操作前会再次确认。建议先导出备份。

Dock 中的“书签”用于管理完整链接库，快速启动器会搜索这里的全部内容。常用入口 Widget
只引用其中被固定到首页的书签；从 Widget 移除不会删除书签，删除 Widget 也不会影响书签库。
浏览器 HTML 书签导入只增加书签，不会改变当前画布。

## 数据保存

NaviDash 目前以本地部署为主，运行数据通常保存在宿主机挂载目录中。

主要包括：

- 全局设置
- widget 布局
- widget 配置

如果你使用 Docker，建议把数据目录挂载到仓库外，例如 `/opt/navidash-data`。

## Demo 模式

如果启用了 Demo 模式：

- 页面可正常浏览和试用
- 前端交互仍可进行
- 刷新后会恢复为默认演示内容
- 所有写入不会真正持久化

这更适合在线展示，不适合作为长期使用环境。

## 常见问题

### 为什么刷新后我的修改消失了？

通常有两种可能：

- 当前运行在 Demo 模式
- 持久化目录没有正确挂载或没有写权限

### 为什么 Today 没有天气数据？

请检查：

- `QWEATHER_API_KEY` 是否已配置
- 容器是否已重启
- 全局设置中的天气连接测试是否成功
- Today 的城市名或经纬度是否有效
- 网络是否可以访问天气服务

### 如何完整备份当前首页？

打开设置面板，在“数据工具”中导出 JSON。  
如果你是 Docker 部署，也建议同时备份宿主机上的数据目录。

### 如何恢复到干净状态？

可以在设置面板中使用重置功能。  
如果需要彻底恢复，也可以删除挂载目录中的运行数据后重新启动容器。
