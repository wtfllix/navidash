# NaviDash 部署与使用 Wiki

这里仅整理个人使用 NaviDash 时需要长期保留的信息。项目内部开发约定不在此展开。

## 推荐部署方式

在家用电脑、NAS 或小型服务器上使用 Docker Compose 运行 NaviDash，并把 `/app/data`
挂载到宿主机目录。局域网中的其他设备通过 `http://部署主机IP:3000` 访问。

完整步骤见 [部署指南](./DEPLOY.md)。首次使用建议依次完成：

1. 创建持久化目录并启动容器。
2. 从手机或另一台电脑验证局域网访问。
3. 按需配置访问密码、天气与 Komari。
4. 在设置中导出一次 JSON，并备份宿主机数据目录。

## 局域网部署要点

- 为部署主机保留固定局域网 IP，避免访问地址变化。
- 不要使用 Demo 模式作为正式实例，否则刷新后不会保留修改。
- 数据目录必须长期存在且可写；升级或重建容器不会代替数据备份。
- 天气、F1 车手积分和 Komari 状态需要部署主机访问对应服务；首页设备只访问 NaviDash。
- 如果需要在外网使用，优先通过可信 VPN 接入家庭网络，不要直接暴露应用端口。
