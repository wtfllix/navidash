# 002：书签库与首页固定入口分离

状态：已接受  
日期：2026-07-25

## 背景

Links Widget 同时保存链接资产和首页展示配置，导致浏览器书签只有出现在画布上才能被快速
启动器检索。大量导入会生成大量 Widget，与注意力优先的主页定位冲突。

## 决策

- 在 Widget 原子快照中增加全局书签库。
- 快速启动器检索整个书签库。
- Links Widget 只保存有序 `bookmarkIds`，用于固定少量入口。
- Dock 提供一级“书签”入口；Widget 设置提供从书签库选择、移除和排序。
- Dock 与 Widget 设置共享批量粘贴解析能力，支持 Markdown 链接与纯 URL；从 Widget
  设置导入时同时固定到当前组件。
- 旧 Links 内联链接按规范化 URL 确定性去重并迁移到书签库。

## 影响

- 导入大量书签不再要求把所有链接铺到画布。
- 同一书签可被多个 Widget 引用，修改标题或 URL 后统一生效。
- 删除 Widget 不删除书签；删除被引用书签时需要提示并清理引用。
