# 003：F1 采用内置赛季数据与只读赛程摘要

状态：已接受  
日期：2026-08-15

## 背景

通用日历要求用户理解 ICS、提供订阅地址或配置 CalDAV 凭据，不符合 NaviDash 低摩擦、
注意力优先的首页定位。F1 赛事属于公开、预先规划且适合快速扫读的个人兴趣内容，但原始
ICS 的标题、赛段分类和状态字段不适合作为 Widget 的运行时契约。

## 决策

- 第一版只实现专用 F1 Widget，不建立通用日历或日程来源平台。
- 原始赛季 ICS 随仓库保留，用于来源追溯和后续更新。
- 开发脚本将 ICS 确定性转换为带中英文名称、UTC 时间、标准赛段类型和状态的 JSON。
- 应用运行时只读取规范化 JSON，不解析 ICS、不请求远程赛历，也不要求用户配置数据源。
- Widget 默认隐藏练习赛，突出下一赛段，并展示同一比赛周末的后续安排。
- 所有时间按浏览器本地时区显示；待确认和赛季结束必须明确呈现。

## 影响

- 用户添加 Widget 后即可使用，不需要理解订阅地址或授权流程。
- 静态赛程不会自动接收临时改期，需要更新源文件并重新生成数据后随版本发布。
- 规范化事件结构可在未来复用，但当前不承诺 MotoGP、RSS、CalDAV 或第三方来源。
- 赛季切换需要新增下一年度源文件和生成数据，不改变已有 Widget 配置。
